# Blender 体积投影模型

普通透视投影仪照射玻璃中的散射点，默认按当前投影仪姿态动态设计点云。当前版本在 Blender 5.2.1 LTS 验证。
默认建立独立的 `VolumeProjection` 场景，保留原场景；重复运行会重新连接控制并保留手动修改。

## 项目文件

- `projector.py`：唯一的模型运行入口，包含建模、材质、光线映射和侧栏控制；不依赖本地 `classes` 或 `utils` 包。
- `tests/test_projection_blender.py`：Blender 回归测试。
- `README.md`、`CHANGELOG.md`、`AGENTS.md`：使用说明、变更历史和维护约定。
- `Nayar_TR06.pdf`：参考论文，保留原文件。
- `outputs/`：可编辑场景、预览及导出数据，保留已有结果。
- `tmp/`、`__pycache__/`：验证临时文件和 Python 缓存，不作为运行入口，不纳入 Git。

旧版根目录 `__init__.py`、`classes/` 和 `utils/` 中的 7 个代码文件已移出工作目录，
因为当前入口和测试均不引用这些模块。原始内容保存在 Git 提交 `167f7cb` 中。
可用 `git show 167f7cb:classes/projector.py` 查看旧实现，不必恢复到当前目录。
本项目通过 Blender 执行独立脚本，不再提供旧版包导入入口。

## 运行与调整

在项目目录的 PowerShell 中运行：

```powershell
& 'G:\SteamLibrary\steamapps\common\Blender\blender.exe' --python projector.py -- --keep-open
```

生成后窗口保持打开，默认选中 `Projector_Body`。在三维视图按 `N`，打开“体积投影”页签。
可以直接移动、旋转投影仪，或在侧栏输入位置、旋转角和相对强度。自动更新约每 0.15 秒检查一次变化。

- 默认不勾选“固定气泡位置”：移动或旋转投影仪后，气泡重新生成在新的像素中心光线上，且必须位于玻璃内部。
- 勾选“固定气泡位置”：保留点云，只更新照明；背向投影仪或超出视场的气泡不发光。这才对应已雕刻玻璃的物理情形。
- “恢复标定位置”恢复最近一次生成点云时的投影仪姿态，不是全局初始位置；自动重建后标定位置也会更新。
- 投影内容提供测试图、全白、深度编码三种模式；照亮数量显示当前响应。
- “像素光线”“散射示意”“参考图像平面”“深度层”分别控制辅助显示。
- “导出坐标和投影图”写入 `outputs/bubble_coordinates.csv` 和 `outputs/projector_input.png`。
- `Ctrl+S` 保存手动修改。重复运行保留场景和参数，必要时刷新派生点云；`--rebuild` 会重建整个演示。

面板中的参数可以直接修改，无需改脚本或重新启动 Blender：

- **水平/垂直 FOV**：完整视场角，单位为度，范围 5° 到 140°。两个方向独立设置。
- **横向/纵向点数**：每个方向 2 到 64 个投影采样，控制点云密度；默认 16 x 10。
- **深度层数**：1 到 32 层，用于沿各条射线分配深度，不与点阵数量相乘。
- **半径上限**：以米为单位；高密度时会自动缩小气泡，避免相邻像素中心射线穿过同一气泡。
- **固定气泡位置**：默认关闭，修改位置、旋转或 FOV 会重新排列气泡；开启后这三类修改只改变光束和照明。

开启“自动更新”时，参数或投影仪姿态停止变化约 0.35 秒后重建点云，实际延迟还包含定时检查和计算时间；关闭后点击“更新投影”应用参数。
改变点数、层数或半径会重新生成气泡，保留投影仪、玻璃、相机和用户另外添加的对象。
新点按当前投影仪姿态生成在光线与玻璃的交段中，未穿过玻璃的射线不生成气泡，
因此实际总数可能小于横向点数乘纵向点数。面板显示实际点数和平均密度（点/立方米）。
重建会把当前投影仪位置记为新的标定位置。未改变参数或姿态时不会反复重建。
没有任何射线穿过玻璃时，总点数变为 0；重新对准玻璃后自动生成。相同参数和姿态可重复得到相同点位。
“固定气泡位置”只锁定位置、旋转和 FOV 的影响，主动修改点数、层数或半径仍然表示重新设计点云。

这些是教学示意的采样网格，不是商业投影仪的原生分辨率。
光线辅助显示默认最多 160 条，`FAST_PREVIEW=False` 时最多 260 条，气泡和照明仍按完整点阵计算。
所有面板参数保存在 `.blend` 中，重复运行脚本保留参数。`--rebuild` 用于从脚本默认值重建整个演示。

## 与论文的关系

参考本目录 `Nayar_TR06.pdf`：Nayar 和 Anand，*Projection Volumetric Display using Passive Optical Scatterers*，CUCS-030-06，2006。

- 第 3 节、图 2：可索引点云要求每个散射点能被独立照亮。随机分配深度/像素对应关系时，点不能离开投影射线。
- 第 4 节、图 4：散射体是激光诱导损伤产生的微裂纹，球体只是几何替代。暗像素的物理散射点仍然存在。
- 第 5 节、图 5：论文主要用菲涅尔透镜将普通投影仪的发散光转换为平行光，改善各深度的分辨率与标定。
- 第 6 节：实际装置需要分层、分色标定。当前采用已知几何的理想透视映射，不复现其多项式标定实验。

本模型依照普通投影仪的要求使用透视射线；每条与玻璃相交的像素中心射线对应一个点。
在相邻的 N 条像素射线间随机排列深度层，再沿射线加入有界深度抖动；N 为面板中的深度层数。
这是对论文索引原则的简化应用，不是图 2 三维点云生成算法或可见率实验的完整复现。

初始位置使用 `P = L + t(T - L)`，其中 `L` 为镜头、`T` 为参考像素位置，`t` 由射线与玻璃交段内的选定深度确定。
参考平面的完整宽度/高度由 `2 * distance * tan(FOV / 2)` 决定，像素中心位于各采样单元中央。
点云通过玻璃局部坐标中的射线/包围盒相交生成，保留气泡半径的边界余量。
默认设计模式下，移动后重新求射线与玻璃交段并生成点位；固定模式下，通过投影仪变换的逆矩阵将已有点映射回像素坐标，并以最近像素单元采样颜色。
CSV 的 `pixel_*_calibrated` 是最近一次点云生成时的索引，`pixel_*_current` 是当前连续像素坐标；超出视场时为空。
坐标单位为米，尺寸和气泡半径均为放大的示意参数，不是论文的制造尺寸。

当前仍属于几何和辐射响应的可视化近似：颜色以发光材质表示，玻璃透明材质用于观察，未计算折射光路、
焦外光斑、串扰、多次散射、裂纹角度响应或绝对光强。金色线表示像素中心射线，有限像素单元内的点也可能被照亮。
可选远侧图像平面是随投影仪移动的参考平面，不是透明玻璃上真实出现的不透明屏幕。
关闭所有辅助显示可单独观察气泡。散射线只表示方向，未实现定量散射模型。

## 使用排查与溯源

1. 在对象模式选中 `Projector_Body`，打开 `N` 侧栏的“体积投影”。
2. 勾选“自动更新”，取消“固定气泡位置”，使用 `G` 移动或 `R` 旋转，确认操作后稍等点云刷新。
3. 如果总数为 0，检查投影是否仍指向玻璃。只看到颜色改变时，检查是否锁定了气泡位置。
4. 若自动更新被暂停，可点击“更新投影”检查报错，修正后重新开启“自动更新”。渲染期间和非对象模式下定时刷新会暂缓。
5. 修改代码后，在已有场景重新运行 `projector.py` 即可连接新控制逻辑，不必关闭窗口。旧场景中的锁定选项值会保留。
