# Blender 体积投影模型

普通透视投影仪向玻璃投射图像，玻璃内的球体直接显示当前光路采样颜色，不再产生散射照明。默认按当前投影仪姿态动态设计点云。当前版本在 Blender 5.2.1 LTS 验证。
默认建立独立的 `VolumeProjection` 场景，保留原场景；重复运行会重新连接控制并保留手动修改。
当前开发分支：`codex/projected-image-scattering`，保留 Cycles 图像投影，点云改为纯颜色显示。

## 项目文件

- `projector.py`：唯一的模型运行入口，包含建模、材质、光线映射和侧栏控制；不依赖本地 `classes` 或 `utils` 包。
- `tests/test_projection_blender.py`：Blender 回归测试。
- `tests/test_optical_render_blender.py`：实际渲染验证，检查 RGB 方向、关灯响应、球体不照亮其他物体和玻璃透射。
- `tests/test_denoise_render_blender.py`：OptiX 下 12 采样的降噪前后对照，检查地面颗粒与高饱和像素保留。
- `README.md`、`CHANGELOG.md`、`AGENTS.md`：使用说明、变更历史和维护约定。
- `Nayar_TR06.pdf`：参考论文，保留原文件。
- `outputs/`：可编辑场景、预览及导出数据，保留已有结果。
- `tmp/`、`__pycache__/`：验证临时文件和 Python 缓存，不作为运行入口，不纳入 Git。

旧版根目录 `__init__.py`、`classes/` 和 `utils/` 中的 7 个代码文件已移出工作目录，
因为当前入口和测试均不引用这些模块。原始内容保存在 Git 提交 `167f7cb` 中。
可用 `git show 167f7cb:classes/projector.py` 查看旧实现，不必恢复到当前目录。
本项目通过 Blender 执行独立脚本，不再提供旧版包导入入口。

## 运行与调整

在项目目录的 PowerShell 中运行：

```powershell
& 'G:\SteamLibrary\steamapps\common\Blender\blender.exe' --python projector.py -- --keep-open
```

生成后窗口保持打开，默认选中 `Projector_Body`。在三维视图按 `N`，打开“体积投影”页签。
可以直接移动、旋转投影仪，或在侧栏输入位置、旋转角和相对强度。自动更新约每 0.15 秒检查一次变化。

- 默认不勾选“固定气泡位置”：移动或旋转投影仪后，气泡重新生成在新的像素中心光线上，且必须位于玻璃内部。
- 勾选“固定气泡位置”：保留点云，只更新照明；背向投影仪或超出视场的气泡不发光。这才对应已雕刻玻璃的物理情形。
- “恢复标定位置”恢复最近一次生成点云时的投影仪姿态，不是全局初始位置；自动重建后标定位置也会更新。
- 投影内容提供测试图、彩条、全白、深度编码和图片模式；照亮数量显示被非黑像素覆盖的点数，不是光度计读数。
- “像素光线”“参考图像平面”“深度层”分别控制辅助显示；不再生成散射示意线。
- “隐藏实体光线”隐藏入射线，作用于三维视图与最终渲染；球体颜色和真实投影不变。取消勾选会恢复原先的“像素光线”设置。
- “导出坐标和投影图”写入 `outputs/bubble_coordinates.csv`、`outputs/projector_input.png` 和 `outputs/projection_settings.json`。
- `Ctrl+S` 保存手动修改。重复运行保留场景和参数，必要时刷新派生点云；`--rebuild` 会重建整个演示。

面板中的参数可以直接修改，无需改脚本或重新启动 Blender：

- **水平/垂直 FOV**：完整视场角，单位为度，范围 5° 到 140°。两个方向独立设置。
- **横向/纵向点数**：每个方向 2 到 64 个投影采样，控制点云密度；默认 16 x 10。
- **深度层数**：1 到 32 层，用于沿各条射线分配深度，不与点阵数量相乘。
- **半径上限**：以米为单位；高密度时会自动缩小气泡，避免相邻像素中心射线穿过同一气泡。
- **固定气泡位置**：默认关闭，修改位置、旋转或 FOV 会重新排列气泡；开启后这三类修改只改变光束和照明。

开启“自动更新”时，参数或投影仪姿态停止变化约 0.35 秒后重建点云，实际延迟还包含定时检查和计算时间；关闭后点击“更新投影”应用参数。
改变点数、层数或半径会重新生成气泡，保留投影仪、玻璃、相机和用户另外添加的对象。
新点按当前投影仪姿态生成在光线与玻璃的交段中，未穿过玻璃的射线不生成气泡，
因此实际总数可能小于横向点数乘纵向点数。面板显示实际点数和平均密度（点/立方米）。
重建会把当前投影仪位置记为新的标定位置。未改变参数或姿态时不会反复重建。
没有任何射线穿过玻璃时，总点数变为 0；重新对准玻璃后自动生成。相同参数和姿态可重复得到相同点位。
“固定气泡位置”只锁定位置、旋转和 FOV 的影响，主动修改点数、层数或半径仍然表示重新设计点云。

这些是教学示意的采样网格，不是商业投影仪的原生分辨率。
光线辅助显示默认最多 160 条，`FAST_PREVIEW=False` 时最多 260 条，气泡和照明仍按完整点阵计算。
所有面板参数保存在 `.blend` 中，重复运行脚本保留参数。`--rebuild` 用于从脚本默认值重建整个演示。

## 图像投影与球体取色

本分支默认使用 Cycles，启动后进入渲染视图；初次着色和采样需要等待。材质预览模式不能作为图像灯光的验证结果。

### GPU 渲染

启动或重新运行新版脚本时自动选择可用的 GPU：优先 OptiX，其后为 CUDA、HIP、oneAPI、Metal；没有兼容设备则在日志中说明并使用 CPU。
本机已检测并验证 **NVIDIA GeForce RTX 3070 Ti Laptop GPU（8GB）/ OptiX**。
配置同时设置 Cycles 后端、启用对应 GPU 并关闭 CPU 混合计算，以及场景的 `GPU Compute`，渲染视口和最终渲染共用该设备选择。
侧栏显示 `Cycles: GPU / OPTIX`；设备探测不在自动更新定时器中运行，旋转视角不会重复枚举硬件。

```powershell
& 'G:\SteamLibrary\steamapps\common\Blender\blender.exe' 'outputs\volume_projection_gpu.blend' --python projector.py -- --keep-open
```

这份 GPU 演示单独保存，原 `volume_projection_color_only.blend` 不变。已有场景运行新版脚本也会切换 GPU，并保留手动位置、点云模式、采样数和最终渲染降噪设置；视口降噪会重新开启。
新建场景仍为最终 32 采样、视口 12 采样；视口现在默认开启降噪，详见下节。首次 GPU 初始化/内核编译仍可能等待，旋转视角仍会重新采样。
脚本不调用“保存偏好设置”：后端选择影响当前 Blender 进程的 Cycles 偏好；场景设备会随 `.blend` 保存，但在另一个进程重新打开时仍建议同时运行脚本以检测本机 GPU。
可在 Blender 渲染属性中手动改回 CPU；定时刷新不会覆盖它，重新运行脚本则再次优先选择 GPU。

验证记录见 `outputs/gpu_render_verification.json`（含脚本 SHA-256）。同一演示、1280 x 820、32 采样并开启最终降噪，连续两次静帧实测 CPU 为 17.55 / 17.22 秒，GPU 为 5.92 / 6.38 秒，包含 PNG 输出。
这是该次运行的静帧对照，不是视口旋转 FPS 或稳定性能保证。显存占用、驱动、初次缓存和其他程序负载都会影响结果；GPU 渲染失败或显存不足不会被静默重试成 CPU。
受限测试环境无法写入默认 OptiX 缓存目录时，驱动会回退到项目内的 `optix7cache.db`，该缓存已忽略，不进入 Git。

### 视口降噪

原视口只有 12 次采样且未开启降噪，GPU 加速本身不会去掉采样颗粒。新版启动或重新连接时启用视口降噪：当前使用 OptiX GPU 时明确选择 OptiX，其他设备使用 Blender 的 AUTO；从第 1 个样本开始允许降噪。
此改动不增加现有采样数，不改变最终渲染的采样、降噪、球体材质或投影 RGB。当前场景可直接重连，不需要 `--rebuild`。
在“体积投影”侧栏取消“视口降噪”可以即时查看原始效果；自动刷新不会重新勾选，但下次运行脚本会恢复开启。开关随 `.blend` 保存。
降噪是图像估计，可能让很细的边缘变柔，不能承诺所有缩放和姿态下都保留亚像素小球；精确检查时可临时关闭。旋转时仍会重采样，并有降噪计算开销，不保证帧率提升。
验证使用相同 12 采样静帧作为视口的近似对照：高饱和彩色像素保留约 99.1%，归一化 RGB 平均误差约 0.0062；地面局部高频指标明显下降。这不是逐球可见率或实际视口性能测量。已在当前未保存场景中重连并目视检查采样完成后的视口：地面和接收屏颗粒减少，彩色点仍可见，保留原有视角及光线显示状态；未测量交互 FPS。
对照及指标输出在 `tmp/denoise_render/`，该目录不纳入 Git；重新运行下面的专项测试即可复现。

1. 运行脚本，打开“体积投影”侧栏，默认测试图会由镜头处的 `Projector_Image_Light` 投射到后方接收屏。
2. 点击“加载投影图片”，选择 PNG/JPG 等静态图像。图片会打包到 `.blend`，投影灯和气泡采样使用同一份图像。
3. “光源功率 (W)”控制真实投影灯；“相对强度”同时缩放灯光和球体显示 RGB。正功率的大小不再额外缩放球体颜色；图像光照开启且功率为零时，球体变黑。
4. 开启“像素光线”查看彩色入射示意。球体按入射 RGB 直接着色，不生成二次点光源或散射短线；“散射比例”和“散射示意”已从侧栏移除。
5. 关闭“接收屏”只观察玻璃中的气泡；接收屏是独立的白色漫反射物体，可以手动移动，不会随投影仪移动。

“图像光照 / Cycles”控制主投影光源；关闭后保留球体取色预览与辅助照明，不切换渲染引擎。
“参考图像平面”是旧版发光像素示意，和真正受光的“接收屏”不同，默认隐藏。
在旧 `.blend` 中重新运行会移除当前场景内脚本生成的散射灯光和短线，并保留投影仪、点云及用户灯光。若旧散射对象或集合被其他场景共享，只解除当前场景的链接（必要时复制集合链接），不删除参考场景中的对象。旧的散射属性即使保留在自定义属性中也不再生效。新建模型默认隐藏密集入射线。

### 玻璃反射简化

玻璃立方体现在使用透明与纯折射的混合材质，不计算其表面镜面反射和漫反射。
仍保留玻璃的透明度、颜色、折射率、粗糙度以及边界轮廓；投影仪镜头材质不变，球体仍按直线光路取色。
旧场景重新运行新版 `projector.py` 会自动转换立方体的原 Principled 材质，无需重建点云。
此项不等于完全关闭折射，也不自动改变 CPU/GPU、采样数或降噪配置，因此不保证消除所有噪点或明显提速。
不能仅将 Principled 的高光强度设为零：测试中其透射部分仍残留反射，因此改用独立 Refraction BSDF。
节点说明见 [Blender Refraction BSDF](https://docs.blender.org/manual/en/latest/render/shader_nodes/shader/refraction.html)。
历史无反射演示为 `outputs/volume_projection_no_reflections.blend`（基于 `3138b45`，仍含旧散射模型）。
新版纯颜色演示另存为 `outputs/volume_projection_color_only.blend`，预览为同名 `.png`，不覆盖历史场景。
配套坐标、采样图和参数另存于 `outputs/color_only/`，其中 JSON 的 `source_sha256` 与场景的 `vp_source_sha256` 记录生成脚本内容；该目录不覆盖旧版导出数据。
这份演示开启“隐藏实体光线”，如需显示光路，取消隐藏并开启“像素光线”。重新打开并连接控制：

```powershell
& 'G:\SteamLibrary\steamapps\common\Blender\blender.exe' 'outputs\volume_projection_color_only.blend' --python projector.py -- --keep-open
```

### 隐藏实体光线

在 `N` 侧栏的“体积投影”页签勾选“隐藏实体光线”，即可只看气泡及投射画面，不显示几何光线。
此时下面的“像素光线”选项暂时置灰，但原来的勾选状态不会被清除。
关闭“自动更新”时，需要点击“更新投影”应用显示选项。隐藏开关不重建气泡，也不关闭光源。
该选项默认关闭，随 `.blend` 保存。旧场景重新运行磁盘上的新版 `projector.py` 后会补齐选项，并保留已有设置；不需要 `--rebuild`。
已打开的旧脚本不会自动升级；在 Blender 文本编辑器中打开新版 `projector.py` 并运行即可重新连接控制。

图片按完整 FOV 矩形拉伸，不自动保持宽高比；想避免变形，请令 `tan(水平FOV/2) / tan(垂直FOV/2)` 接近图片宽高比。
屏幕投射使用原图分辨率；每个气泡按当前光路在原图上的实际 UV 最近邻取色，不先舍入到低分辨率点阵。
导出的 `projector_input.png` 仍是点阵中心的采样图，固定点偏离中心射线后不能拿它替代原图判断点颜色。
当前支持静态图，不处理视频帧。图片加载后为内存快照，外部修改图片后请再次加载。
点数增大会增加几何对象和取色计算量，但不再增加二次光源。先使用默认 16 x 10 验证，再逐步增加。

### 检查气泡颜色

在投影内容中选择“彩条”，取消“隐藏实体光线”并开启“像素光线”，可以看到红、绿、蓝、青、品红、黄六组光路。
每个气泡与照射它的光线同色，只受相对强度缩放，不受旧散射比例影响，也不随机分配颜色。
“测试图”本身包含白色图案，因此部分白点是正常结果；需要演示不同颜色时使用“彩条”或加载彩色图片。
开启“固定气泡位置”后移动投影仪，点保持原位，但会根据新的入射方向重新取色；超出 FOV 或转到投影仪背后的点变暗。
CSV 的 `incident_r`、`incident_g`、`incident_b` 记录未乘相对强度的线性入射 RGB，便于逐点核查。

### 近似模型与边界

主光源使用带图像纹理的聚光灯，按局部方向计算透视 UV，随镜头位置、旋转和 FOV 联动。
球体使用当前投影仪的逆变换求取 UV，再对原图最近邻取色：

```text
incident_rgb = sample_source_image(projector_uv(point_world))
sphere_rgb = incident_rgb * relative_power
```

超出 FOV、位于镜头后方或落在黑色像素上的球体显示黑色。开启图像光照时，零瓦功率也将显示颜色归零。
球体使用仅对相机光路可见的颜色材质，显示强度为 1；材质内部的 Emission 节点仅用于显示，不会照亮周围物体。
这不是散射仿真或光强测量，不包含距离衰减、散射比例和功率标定。显示还会受到视图色彩管理以及玻璃外观的影响。
CSV 为兼容旧工具保留 `scattered_w_approx` 列，但值始终为零；JSON 的模型标识改为 `pinhole_color_sampling`，不再导出散射比例。

玻璃外壳不遮挡光源阴影，保持直线投影假设；其外观材质已去掉表面反射，但保留视觉折射。
尚未模拟进入玻璃后的 Snell 折射、焦外光斑、裂纹角分布、多次散射、入射遮挡检测或主光束的能量扣除。
所以不能据此宣称完整能量守恒，也不宜用于实际光强或加工参数预测。论文中的真实散射体是微裂纹，当前球体只是位置和颜色的可视化替代。

`projection_settings.json` 记录 FOV、点数、光照参数、投影仪变换和脚本 SHA-256，便于区分实验版本；原始图片打包在场景中。

## 与论文的关系

参考本目录 `Nayar_TR06.pdf`：Nayar 和 Anand，*Projection Volumetric Display using Passive Optical Scatterers*，CUCS-030-06，2006。

- 第 3 节、图 2：可索引点云要求每个散射点能被独立照亮。随机分配深度/像素对应关系时，点不能离开投影射线。
- 第 4 节、图 4：散射体是激光诱导损伤产生的微裂纹，球体只是几何替代。暗像素的物理散射点仍然存在。
- 第 5 节、图 5：论文主要用菲涅尔透镜将普通投影仪的发散光转换为平行光，改善各深度的分辨率与标定。
- 第 6 节：实际装置需要分层、分色标定。当前采用已知几何的理想透视映射，不复现其多项式标定实验。

本模型依照普通投影仪的要求使用透视射线；每条与玻璃相交的像素中心射线对应一个点。
在相邻的 N 条像素射线间随机排列深度层，再沿射线加入有界深度抖动；N 为面板中的深度层数。
这是对论文索引原则的简化应用，不是图 2 三维点云生成算法或可见率实验的完整复现。

初始位置使用 `P = L + t(T - L)`，其中 `L` 为镜头、`T` 为参考像素位置，`t` 由射线与玻璃交段内的选定深度确定。
参考平面的完整宽度/高度由 `2 * distance * tan(FOV / 2)` 决定，像素中心位于各采样单元中央。
点云通过玻璃局部坐标中的射线/包围盒相交生成，保留气泡半径的边界余量。
默认设计模式下，移动后重新求射线与玻璃交段并生成点位；固定模式下，通过投影仪变换的逆矩阵将已有点映射回像素坐标，并以最近像素单元采样颜色。
CSV 的 `pixel_*_calibrated` 是最近一次点云生成时的索引，`pixel_*_current` 是当前连续像素坐标；超出视场时为空。
坐标单位为米，尺寸和气泡半径均为放大的示意参数，不是论文的制造尺寸。

当前属于几何与投影颜色的可视化，不再模拟散射辐射响应，具体模型和缺失项见上文。彩色线表示像素中心射线，有限像素单元内的点也可能被照亮。
可选远侧图像平面是随投影仪移动的参考平面，不是透明玻璃上真实出现的不透明屏幕。
关闭所有辅助显示可单独观察气泡；不存在散射短线或气泡二次光源。

## 使用排查与溯源

1. 在对象模式选中 `Projector_Body`，打开 `N` 侧栏的“体积投影”。
2. 勾选“自动更新”，取消“固定气泡位置”，使用 `G` 移动或 `R` 旋转，确认操作后稍等点云刷新。
3. 如果总数为 0，检查投影是否仍指向玻璃。只看到颜色改变时，检查是否锁定了气泡位置。
4. 若自动更新被暂停，可点击“更新投影”检查报错，修正后重新开启“自动更新”。渲染期间和非对象模式下定时刷新会暂缓。
5. 修改代码后，在已有场景重新运行 `projector.py` 即可连接新控制逻辑，不必关闭窗口。旧场景中的锁定选项值会保留。
