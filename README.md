普通透视投影仪向玻璃投射图像，玻璃内的球体直接显示当前光路采样颜色，不再产生散射照明。默认按当前投影仪姿态动态设计点云。当前版本在 Blender 5.2.1 LTS 验证。
默认建立独立的 `VolumeProjection` 场景，保留原场景；重复运行会重新连接控制并保留手动修改。
当前开发分支：`codex/projected-image-scattering`，保留 Cycles 图像投影，点云改为纯颜色显示。

## 项目文件

- `projector.py`：主要模型运行入口，包含建模、材质、光线映射和侧栏控制；不依赖本地 `classes` 或 `utils` 包。
- `point_cloud_animation.py`：动画网格采样、原始网格预览打包、版本化 JSON 校验及旋转立方体源动画。动画功能需要它与 `projector.py` 位于同一目录。
- `demo_rotating_cube.py`：独立生成并播放旋转立方体投影测试，不修改其他 Blender 进程中的场景。
- `tests/test_animation_blender.py`：动画导出、导入、时间轴、变形网格和颜色映射回归。
- `tests/test_projection_blender.py`：Blender 回归测试。
- `tests/test_optical_render_blender.py`：实际渲染验证，检查 RGB 方向、关灯响应、球体不照亮其他物体和玻璃透射。
- `tests/test_denoise_render_blender.py`：OptiX 下 12 采样的降噪前后对照，检查地面颗粒与高饱和像素保留。
- `README.md`、`CHANGELOG.md`、`AGENTS.md`：使用说明、变更历史和维护约定。
- `Nayar_TR06.pdf`：参考论文，保留原文件。
- `outputs/`：可编辑场景、预览及导出数据，保留已有结果。
- `tmp/`、`__pycache__/`：验证临时文件和 Python 缓存，不作为运行入口，不纳入 Git。

## 运行与调整

在项目目录的 PowerShell 中运行：

```powershell
& 'G:\SteamLibrary\steamapps\common\Blender\blender.exe' --python projector.py -- --keep-open
```

生成后窗口保持打开，默认选中 `Projector_Body`。在三维视图按 `N`，打开“体积投影”页签。
可以直接移动、旋转投影仪，或在侧栏输入位置、旋转角和相对强度。自动更新约每 0.15 秒检查一次变化。

- 默认不勾选“固定气泡位置”：移动或旋转投影仪后，气泡重新生成在新的像素中心光线上，且必须位于玻璃内部。
- 勾选“固定气泡位置”：保留点云，只更新照明；背向投影仪或超出视场的气泡不发光。这才对应已雕刻玻璃的物理情形。
- “恢复标定位置”恢复最近一次生成点云时的投影仪姿态，不是全局初始位置；自动重建后标定位置也会更新。
- 投影内容提供测试图、彩条、全白、深度编码和图片模式；照亮数量显示被非黑像素覆盖的点数，不是光度计读数。
- “像素光线”“参考图像平面”“深度层”分别控制辅助显示；不再生成散射示意线。
- “隐藏实体光线”隐藏入射线，作用于三维视图与最终渲染；球体颜色和真实投影不变。取消勾选会恢复原先的“像素光线”设置。
- “导出坐标和投影图”写入 `outputs/bubble_coordinates.csv`、`outputs/projector_input.png` 和 `outputs/projection_settings.json`。
- `Ctrl+S` 保存手动修改。重复运行保留场景和参数，必要时刷新派生点云；`--rebuild` 会重建整个演示。

面板中的参数可以直接修改，无需改脚本或重新启动 Blender：

- **水平/垂直 FOV**：完整视场角，单位为度，范围 5° 到 140°。两个方向独立设置。
- **横向/纵向点数**：每个方向 2 到 64 个投影采样，控制点云密度；默认 16 x 10。
- **深度层数**：1 到 32 层，用于沿各条射线分配深度，不与点阵数量相乘。
- **半径上限**：以米为单位；高密度时会自动缩小气泡，避免相邻像素中心射线穿过同一气泡。
- **固定气泡位置**：默认关闭，修改位置、旋转或 FOV 会重新排列气泡；开启后这三类修改只改变光束和照明。

开启“自动更新”时，参数或投影仪姿态停止变化约 0.35 秒后重建点云，实际延迟还包含定时检查和计算时间；关闭后点击“更新投影”应用参数。
改变点数、层数或半径会重新生成气泡，保留投影仪、玻璃、相机和用户另外添加的对象。
新点按当前投影仪姿态生成在光线与玻璃的交段中，未穿过玻璃的射线不生成气泡，
因此实际总数可能小于横向点数乘纵向点数。面板显示实际点数和平均密度（点/立方米）。
重建会把当前投影仪位置记为新的标定位置。未改变参数或姿态时不会反复重建。
没有任何射线穿过玻璃时，总点数变为 0；重新对准玻璃后自动生成。相同参数和姿态可重复得到相同点位。
“固定气泡位置”只锁定位置、旋转和 FOV 的影响，主动修改点数、层数或半径仍然表示重新设计点云。

这些是教学示意的采样网格，不是商业投影仪的原生分辨率。
光线辅助显示默认最多 160 条，`FAST_PREVIEW=False` 时最多 260 条，气泡和照明仍按完整点阵计算。
所有面板参数保存在 `.blend` 中，重复运行脚本保留参数。`--rebuild` 用于从脚本默认值重建整个演示。

导出自己的 Blender 动画：

1. 在动画文件中运行 `projector.py` 注册面板。它会创建独立投影场景，原动画场景仍保留；在顶部场景选择器切回原动画场景。
2. 选中需要转换的 Mesh 对象，设置时间轴开始、结束帧及场景 FPS。
3. 在“体积投影 → 动画点云导出”点击“导出选中网格动画”，选择 JSON 路径和每帧表面采样数。完成后恢复源场景原来的帧及子帧。
4. 切回 `VolumeProjection`，点击“导入点云动画”。导入会将目标时间轴设为 1 到动画帧数，设置源 FPS 并跳到第 1 帧，不修改投影仪位置、点数或固定点模式。
5. 点击播放/暂停按钮，或拖动时间轴逐帧查看。“点云匹配半径”控制表面厚度，过小会漏点，过大会让轮廓变厚；返回测试图或图片模式可停止使用动画颜色。

已有投影场景中也可以点击“旋转立方体测试”，生成 JSON 并导入；该按钮保留原有点数和视角。此按钮生成原始 2 米立方体，若旋转时装不下，缩小尺寸或关闭“保持实际尺寸”。默认 16 x 10 点较稀疏，可手动提高点数；独立演示使用 64 x 48 点和 1 米立方体。

**深度补偿与实际尺寸**

- 图片/测试图/彩条/全白模式：开启“深度等尺寸补偿”，设置“目标宽度 (m)”和“目标高度 (m)”。目标以玻璃中心为原点，沿玻璃局部 X/Z 轴铺设，沿局部 Y 深度保持相同尺寸。宽高独立设置，图片纵横比应自行保持。深度编码模式不应用此补偿。
- 补偿计算：对每个现有气泡，取其玻璃局部米制坐标 `x,z`，用 `u=x/width+0.5`、`v=z/height+0.5` 取目标颜色，再用原透视模型把它写回投影像素。投影图会预畸变，而光线仍从镜头发散；球体、投影灯纹理、实体光线和导出的投影 PNG 共用补偿结果。补偿范围外为黑色，共像素冲突时仍按 RGB 最大值合并，不能分别控制同一像素照到的多个深度。
- 动画：新导出 JSON v1 增加可选 `meters_per_normalized_unit`，等于源场景 `unit_settings.scale_length / normalization_scale`。导入含此字段的新动画默认开启“保持实际尺寸”，恢复源模型实际比例，与投影距离/FOV 无关；原始绝对位置仍居中到玻璃，不恢复源世界坐标。
- “整段范围最长边 (m)”是整段动画共同包围盒的最长边，**不是当前帧边长，也不是立方体本身边长**。修改它会等比例缩放整段运动和实体对比预览；例如减半即将模型边长减半。超出玻璃时显示警告，不会偷偷缩小。关闭“保持实际尺寸”会切回原来的自动适配玻璃模式。
- 旧 JSON 没有单位字段时继续自动适配；可以手动开启实际尺寸并输入尺寸。旧 `.blend` 重连也默认保留原来的缩放行为。单位以 Blender 的 `scale_length` 为准，若源场景单位设置有误，应在导出前修正。
- “一样大”指三维目标的物理尺寸，不代表屏幕上的像素尺寸：相机透视仍会使距离相机较远的对象看起来较小。稀疏气泡、匹配厚度、像素量化、视场外截断和共像素冲突仍会带来误差。此版本没有玻璃折射或真实投影仪标定，不能保证真实硬件达到精确尺寸。
- 导出坐标 CSV 的 `x_m/y_m/z_m` 按目标场景 `scale_length` 转换为米；`projection_settings.json` 记录场景单位和补偿/尺寸参数，`projector_matrix_world` 仍为 Blender 原生坐标。默认 1 BU = 1 m 的旧工程数值不变。

米制版验证：20 项动画、43 项投影回归及原有光学渲染检查通过，包含不同深度的等尺寸目标坐标、2 米源边长恢复/缩小为 1 米、厘米单位、距离/FOV 不改变目标尺寸、旧文件回退、补偿灯纹理与气泡颜色一致性以及米制 CSV。米制立方体第 1、13 帧已离线渲染检查；这些是理想几何映射验证，不是对稀疏显示轮廓或真实硬件的尺寸精度保证。本次未重跑降噪专项或验证 GUI 连续播放。测试进程均确认退出且无直接子进程残留。

**原始动画对比预览**

新版导出会将每帧求值后的原始三角网格与颜色一同打包，导入后默认在玻璃旁显示实体预览。它与投影点云使用同一帧索引、循环/FPS 换算及等比例缩放；拖动时间轴、播放或暂停，两者同步。预览使用导出时的实际网格，不是从稀疏点云重建，支持已求值的形态键变形；重新打开打包场景也不依赖原始 `.blend`。
侧栏“原始动画实体预览”控制隐藏/显示，“预览偏移”调整实体模型相对玻璃的位置（沿玻璃的局部轴，单位为米）。直接修改派生预览对象的位置会被下一帧更新覆盖，请使用偏移控件；关闭预览不会改变投影图或气泡颜色。实体使用仅相机可见的颜色材质，不遮挡投影光路、不投射阴影或给场景补光。
旧版仅含 `points` 的 JSON 和 `.blend` 仍可播放，但会显示“无原始网格预览，请重新导出”。不能从旧数据完整恢复原网格，也不会用点云伪装原始实体。重新导出原动画或点击新版“旋转立方体测试”即可获得实体对比。
原始预览保留几何形状及导出用的材质显示色，不是原场景完整渲染：不含贴图、着色节点、透明材质、灯光及未展开实例。实际完整源动画仍可在原场景中查看、修改后重新导出。

**映射规则与限制**

- 导出逐帧求值后的网格，包含对象变换和已求值的形态键/网格修改器；对三角面按世界空间面积进行确定性采样。仅采样选中的 Mesh，不遍历实例；Geometry Nodes 实例应先 Realize Instances，曲线/文字应先转为 Mesh。
- 用整段动画原始求值网格共用的包围盒进行一次等比例归一化到约 `[-0.8, 0.8]`，保留相对运动和大小，不逐帧居中。原始中心和缩放记录在元数据中；新增米制字段支持恢复真实尺寸。相比早期按随机表面样本求包围盒，重新导出的缩放可能略有变化。
- RGB 是线性颜色，来自材质的 Viewport Display/Diffuse Color，缺少材质时使用对象颜色。不烘焙节点、纹理、灯光或透明度；带贴图的模型必须先另行烘焙/转换颜色，此版本不宣称复现完整渲染外观。
- 目标点云居中放置；适配模式按玻璃最短边缩放，实际尺寸模式按指定米制尺寸缩放。用 KDTree 查询气泡到最近目标表面样本的距离；匹配半径仍相对于玻璃最短半边长，不随模型缩放变化。匹配后生成每个投影像素的 RGB，气泡、真实投影灯纹理与实体光线共用此帧。
- 可选“精确网格表面匹配”：有嵌入网格时改用 BVH 查询最近三角面距离及该面的材质显示色，减少随机点样本空隙造成的漏点，不是移动气泡或增加独立深度寻址。没有网格的旧 JSON 自动使用原 KDTree；空点云帧仍保持黑色。默认导入保留原点云匹配行为，清晰版独立演示主动启用该选项。关闭“原始动画实体预览”不会关闭网格匹配。
- 播放不移动气泡，也不把动画点直接伪装成可独立寻址的显示点。手动移动投影仪仍遵守原有设计/固定点模式。多气泡落入同一投影像素时按 RGB 分量最大值合并，它们会显示相同颜色，面板报告冲突数；单台投影仪不能在同一光线上独立控制不同深度。
- 这是稀疏体积表面近似，不是连续实体或完整光学仿真。轮廓受气泡布局、点数、匹配半径和视角限制；源点增多不等于实际显示像素增多。
- 使用时间轴 FPS 换算源帧，逐帧取样、不插值；开启循环时取模，关闭时超出范围保持首/尾帧。Blender 自身的时间轴循环仍由播放范围决定，取消此开关不会自动停止时间轴。修改目标 FPS 后需要自行调整播放结束帧。
- 导入最多 64 MiB、2000 帧、总计 500000 个点；导出每帧 1..20000 个点且同样限制总数。原始预览另外限制整段动画 500000 个顶点、1000000 个三角面、每帧 256 种颜色，超限需简化网格或缩短动画。空帧显示黑色；格式版本、有限数值、坐标、颜色、面索引及源帧号均进行校验。导出会同步计算全部帧，大任务会暂时占用 UI。
- 动画由 `frame_change_post` 驱动，渲染也更新帧；导入时开启 Render Lock Interface，避免渲染线程与界面同时访问被修改的数据，依据 [Blender 官方 handler 说明](https://docs.blender.org/api/5.2/bpy.app.handlers.html)。不保证 Cycles 实时达到源 FPS。

**JSON v1**：`format="volume_projection_point_animation"`、`version=1`、`coordinates="normalized_isotropic"`、`color_space="linear_rgb"`、`fps`、`frames=[{"source_frame":1,"points":[[x,y,z,r,g,b], ...]}, ...]`；帧数组顺序决定播放顺序，`source_frame` 仅用于溯源。普通投影仪不能直接读取此 JSON，需先导入模拟器映射为二维图像；现有“导出坐标和投影图”导出当前帧的投影 PNG。

兼容扩展：每帧可选 `preview={"vertices":[[x,y,z],...],"triangles":[[i,j,k,color_index],...],"colors":[[r,g,b],...]}`，坐标归一化方式及线性颜色与 `points` 一致。没有该字段时不提供原始实体预览。

### 近似模型与边界

主光源使用带图像纹理的聚光灯，按局部方向计算透视 UV，随镜头位置、旋转和 FOV 联动。
球体使用当前投影仪的逆变换求取 UV，再对原图最近邻取色：

```text
incident_rgb = sample_source_image(projector_uv(point_world))
sphere_rgb = incident_rgb * relative_power
```

超出 FOV、位于镜头后方或落在黑色像素上的球体显示黑色。开启图像光照时，零瓦功率也将显示颜色归零。
球体使用仅对相机光路可见的颜色材质，显示强度为 1；材质内部的 Emission 节点仅用于显示，不会照亮周围物体。
这不是散射仿真或光强测量，不包含距离衰减、散射比例和功率标定。显示还会受到视图色彩管理以及玻璃外观的影响。
CSV 为兼容旧工具保留 `scattered_w_approx` 列，但值始终为零；JSON 的模型标识改为 `pinhole_color_sampling`，不再导出散射比例。

玻璃外壳不遮挡光源阴影，保持直线投影假设；其外观材质已去掉表面反射，但保留视觉折射。
尚未模拟进入玻璃后的 Snell 折射、焦外光斑、裂纹角分布、多次散射、入射遮挡检测或主光束的能量扣除。
所以不能据此宣称完整能量守恒，也不宜用于实际光强或加工参数预测。论文中的真实散射体是微裂纹，当前球体只是位置和颜色的可视化替代。

`projection_settings.json` 记录 FOV、点数、光照参数、投影仪变换和脚本 SHA-256，便于区分实验版本；原始图片打包在场景中。

## 与论文的关系

参考本目录 `Nayar_TR06.pdf`：Nayar 和 Anand，*Projection Volumetric Display using Passive Optical Scatterers*，CUCS-030-06，2006。

- 第 3 节、图 2：可索引点云要求每个散射点能被独立照亮。随机分配深度/像素对应关系时，点不能离开投影射线。
- 第 4 节、图 4：散射体是激光诱导损伤产生的微裂纹，球体只是几何替代。暗像素的物理散射点仍然存在。
- 第 5 节、图 5：论文主要用菲涅尔透镜将普通投影仪的发散光转换为平行光，改善各深度的分辨率与标定。
- 第 6 节：实际装置需要分层、分色标定。当前采用已知几何的理想透视映射，不复现其多项式标定实验。

本模型依照普通投影仪的要求使用透视射线；每条与玻璃相交的像素中心射线对应一个点。
在相邻的 N 条像素射线间随机排列深度层，再沿射线加入有界深度抖动；N 为面板中的深度层数。
这是对论文索引原则的简化应用，不是图 2 三维点云生成算法或可见率实验的完整复现。

初始位置使用 `P = L + t(T - L)`，其中 `L` 为镜头、`T` 为参考像素位置，`t` 由射线与玻璃交段内的选定深度确定。
参考平面的完整宽度/高度由 `2 * distance * tan(FOV / 2)` 决定，像素中心位于各采样单元中央。
点云通过玻璃局部坐标中的射线/包围盒相交生成，保留气泡半径的边界余量。
默认设计模式下，移动后重新求射线与玻璃交段并生成点位；固定模式下，通过投影仪变换的逆矩阵将已有点映射回像素坐标，并以最近像素单元采样颜色。
CSV 的 `pixel_*_calibrated` 是最近一次点云生成时的索引，`pixel_*_current` 是当前连续像素坐标；超出视场时为空。
坐标单位为米，尺寸和气泡半径均为放大的示意参数，不是论文的制造尺寸。

当前属于几何与投影颜色的可视化，不再模拟散射辐射响应，具体模型和缺失项见上文。彩色线表示像素中心射线，有限像素单元内的点也可能被照亮。
可选远侧图像平面是随投影仪移动的参考平面，不是透明玻璃上真实出现的不透明屏幕。
关闭所有辅助显示可单独观察气泡；不存在散射短线或气泡二次光源。

## 使用排查与溯源

1. 在对象模式选中 `Projector_Body`，打开 `N` 侧栏的“体积投影”。
2. 勾选“自动更新”，取消“固定气泡位置”，使用 `G` 移动或 `R` 旋转，确认操作后稍等点云刷新。
3. 如果总数为 0，检查投影是否仍指向玻璃。只看到颜色改变时，检查是否锁定了气泡位置。
4. 若自动更新被暂停，可点击“更新投影”检查报错，修正后重新开启“自动更新”。渲染期间和非对象模式下定时刷新会暂缓。
5. 修改代码后，在已有场景重新运行 `projector.py` 即可连接新控制逻辑，不必关闭窗口。旧场景中的锁定选项值会保留。
